# Anti Slop

Stub, not a playbook. No pack plugin covers an AI-tells sweep one to one. The nearest in [LibreCopy-Claude-Code](https://github.com/HermeticOrmus/LibreCopy-Claude-Code) are [`style-guides`](https://github.com/HermeticOrmus/LibreCopy-Claude-Code/tree/main/plugins/style-guides) (voice rules with Vale enforcement) and [`documentation-testing`](https://github.com/HermeticOrmus/LibreCopy-Claude-Code/tree/main/plugins/documentation-testing) (write-good checks for weasel words and adverbs): `grok plugin install style-guides@libre-copy-grok --trust`. The pack README sends slop sweeps to the companion repo [markdown-discipline-skills](https://github.com/HermeticOrmus/markdown-discipline-skills), which is not in this marketplace.

Strip AI-doc tells: adjective stacks, soft closes, empty catalogs.

## Steps
1. Kill vague intensifiers.
2. Prefer concrete nouns.
3. Cut soft closes.
4. One claim per sentence.
5. Re-read out loud.
